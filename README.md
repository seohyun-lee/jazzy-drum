# jazzy drums

플레이: https://seohyun-lee.github.io/jazzy-drum/

출퇴근길에 짧게 재즈와 보사노바 리듬을 연주하는 웹게임의 첫 프로토타입입니다. 상단 한 줄 악보로 타이밍을 보고, 칠 드럼에는 1초 전부터 표시가 나타납니다. 0.5초 전부터 표시가 선명해집니다.

곡 선택 화면에서 보사노바, 스윙, 재즈 왈츠, 재즈 펑크, 모던 재즈의 다섯 가지 자체 제작 패턴을 고를 수 있습니다. 곡마다 BPM, 박자, 드럼 채보, 베이스와 코드 반주가 다릅니다. 즉흥 리듬 모드에서는 드럼을 일정하게 네 번 치면 그 속도로 반주가 시작되고, 이후 연주 속도를 따라 템포가 천천히 변합니다.

곡 목록은 채보 난이도순입니다: 퇴근길 보사노바(EASY), 푸른 골목의 왈츠(EASY+), 막차 뒤 스윙(NORMAL), 주머니 속 그루브(HARD), 새벽의 블루 노트(EXPERT). 각 곡 카드에 난이도를 BPM 앞에 표시합니다.

곡 카드를 누르면 해당 곡의 정답 드럼 채보와 반주가 미리 재생됩니다. 미리 듣기 버튼으로 끄거나 다시 켤 수 있으며, 연주를 시작하면 미리 듣기는 멈춥니다. 새벽의 블루 노트는 마디마다 다른 드럼 변주를 쓰고 라이드와 하이햇 구간이 교차합니다.

## 실행

Node.js 20 이상에서:

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 `dist/`에 생성됩니다.

## 연주

- 왼손 쪽: 하이햇 `D`, 크래시 1 `F`, 하이햇 페달 `C`, 스네어 `V`, 하이 탐 `G`
- 오른손 쪽: 로우 탐 `H`, 크래시 2 `J`, 라이드 `K`, 플로어 탐 `N`
- 킥: 스페이스바 (악보에는 `SP`로 표시)
- 모바일에서는 각 드럼과 두 페달을 직접 터치합니다.
- 가이드 버튼으로 드럼 위 타격 위치 표시를 끌 수 있습니다.
- 악보 방식은 노트가 움직이는 방식과 악보를 고정한 채 판정선이 이동하는 방식 중 선택합니다. 고정 악보는 넓은 화면에서 두 마디씩, 좁은 화면에서 한 마디씩 보여줍니다. 노트 이동 방식의 악보 속도는 2·4·6초 미리보기 중 선택하며 기본값은 보통 4초입니다. 연주 BPM과 별개로 조절합니다.
- 곡 선택 또는 일시정지 화면에서 연주 BPM을 40~180으로 조절합니다. 절반·75%·원곡 속도 버튼도 제공합니다. 반주와 판정 채보가 함께 조정되며 일시정지 중 바꾸면 같은 박자 위치에서 이어집니다.
- `Esc` 또는 일시정지 버튼으로 멈춥니다.
- 상단 **전체화면** 버튼으로 브라우저의 전체화면 모드를 켜고 끌 수 있습니다. 브라우저가 전체화면 API를 지원하지 않으면 버튼이 비활성화됩니다.
- 모바일 전체화면에서는 한 줄 악보를 위에 고정하고 남은 화면을 드럼에 사용합니다. 지원되는 모바일 브라우저에서는 가로 방향 전환도 요청합니다.
- 한글 입력 상태에서도 표시된 키의 물리적 위치(`D`, `V`, `K`, `Space` 등)로 연주할 수 있습니다.

## 내 음악 자동 채보

드럼 채보의 정확도가 충분하지 않아 이 모드는 화면에서 숨겼습니다. 분석 코드는 보관해 두었습니다.

## 배포

`main`에 푸시하면 GitHub Actions가 테스트와 빌드를 실행한 뒤 GitHub Pages에 배포합니다. 저장소의 Settings → Pages에서 배포 소스는 **GitHub Actions**로 설정합니다.

다섯 곡은 모두 자체 제작 패턴입니다. 드럼과 반주는 브라우저의 Web Audio API로 생성합니다. 라이드는 독립된 벨과 금속 잔향으로, 두 크래시는 각각 다른 음색과 길이로 합성합니다. 실제 드럼 녹음 샘플은 아닙니다.

## 구조

- `src/chart.js`: BPM, 곡과 파트별 노트 데이터, 악기 메타데이터
- `src/audio.js`: 브라우저 안에서 만드는 드럼·심벌, 베이스, 코드 반주
- `src/main.js`: 연주 화면, 오디오 시계 기준 판정, 입력과 결과
- `src/jam.js`: 네 번의 타격으로 BPM 측정, 즉흥 반주 템포 추종
- `src/style.css`: 반응형 화면과 드럼 타격 영역
- `public/assets/drum-kit-labelled.png`: 참고 사진의 심벌 배치와 표면 로고를 반영한 현재 드럼 원화
- `public/assets/drum-kit.png`: 이전 심벌 배치 원화
- `public/assets/drum-kit-v1.png`: 이전 드럼 원화 보관본

합주 확장을 위해 곡의 노트는 `parts.drums` 아래에 저장합니다. 실제 다중 악기 네트워크 합주는 아직 구현되지 않았습니다.
