# jazzy drums

출퇴근길에 짧게 재즈와 보사노바 리듬을 연주하는 웹게임의 첫 프로토타입입니다. 상단 한 줄 악보로 타이밍을 보고, 칠 드럼에는 1초 전부터 표시가 나타납니다. 0.5초 전부터 표시가 선명해집니다.

곡 선택 화면에서 보사노바, 스윙, 재즈 왈츠, 재즈 펑크의 네 가지 자체 제작 패턴을 고를 수 있습니다. 곡마다 BPM, 박자, 드럼 채보, 베이스와 코드 반주가 다릅니다.

## 실행

Node.js 20 이상에서:

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 `dist/`에 생성됩니다.

## 연주

- 하이햇: `F`, 스네어: `J`, 킥: `Space`
- 하이 탐: `D`, 로우 탐: `K`, 플로어 탐: `L`
- 왼쪽 크래시 1: `A`, 오른쪽 크래시 2: `E`, 오른쪽 라이드: `S`, 하이햇 페달: `G`
- 모바일에서는 각 드럼과 두 페달을 직접 터치합니다.
- 가이드 버튼으로 드럼 위 타격 위치 표시를 끌 수 있습니다.
- 악보 속도는 2·4·6·8초 미리보기 중 선택하며 기본값은 6초입니다. 연주 BPM과 별개로 조절합니다.
- 곡 선택 또는 일시정지 화면에서 연습 BPM을 40~180으로 조절합니다. 절반·75%·원곡 속도 버튼도 제공합니다. 반주와 판정 채보가 함께 조정되며 일시정지 중 바꾸면 같은 박자 위치에서 이어집니다.
- `Esc` 또는 일시정지 버튼으로 멈춥니다.
- 한글 입력 상태에서도 표시된 키의 물리적 위치(`F`, `J`, `Space` 등)로 연주할 수 있습니다.

네 곡은 모두 30~40초 분량의 자체 제작 패턴입니다. 드럼과 반주는 브라우저의 Web Audio API로 생성합니다. 라이드는 독립된 벨과 금속 잔향으로, 두 크래시는 각각 다른 음색과 길이로 합성합니다. 실제 드럼 녹음 샘플은 아닙니다.

## 구조

- `src/chart.js`: BPM, 곡과 파트별 노트 데이터, 악기 메타데이터
- `src/audio.js`: 브라우저 안에서 만드는 드럼·심벌, 베이스, 코드 반주
- `src/main.js`: 연주 화면, 오디오 시계 기준 판정, 입력과 결과
- `src/style.css`: 반응형 화면과 드럼 타격 영역
- `public/assets/drum-kit-labelled.png`: 참고 사진의 심벌 배치와 표면 로고를 반영한 현재 드럼 원화
- `public/assets/drum-kit.png`: 이전 심벌 배치 원화
- `public/assets/drum-kit-v1.png`: 이전 드럼 원화 보관본

합주 확장을 위해 곡의 노트는 `parts.drums` 아래에 저장합니다. MP3/YouTube 자동 분석과 실제 다중 악기 네트워크 합주는 아직 구현되지 않았습니다.
